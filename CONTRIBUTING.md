# Contributing

Thanks for helping keep this list useful. Open a pull request, or an issue if you'd rather
suggest a site without editing the list.

## What belongs here

- Websites, databases and tools that are useful for Belgian law or the Belgian judiciary.
- Official and free sources first. Paid databases are welcome when they're widely used; mark
  them *Paid.*
- One entry per resource. Not individual law firms, consultants or other advertising.

## How to add an entry

- Put it in the section that fits best, at the end of that section.
- Use this format, with a description in English that ends with a full stop:

  ```markdown
  - [Name](https://link) - What it is and what you'd use it for.
  ```

- Use the name the site uses for itself. For bilingual names, give both: `Dutch / French`.
- Link to the site's own page, not to a search result or a tracking link.
- Check that the link works.

## Broken or outdated links

A [daily check](.github/workflows/links.yml) tests every link and keeps an issue open while one
fails, closing it once they all work again. If a site moved or closed, open a pull request that
updates or removes the entry.
